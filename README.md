# Bengali LLM Benchmark Reliability Audit — Companion Scripts

These scripts implement the zero-cost audit protocol in Appendix A of the manuscript.
They are **ready-to-adapt skeletons**: run the pilot (Step 3) first, fix any
environment-specific issues (dataset paths, gated-model access), then scale up.

## Run order

| # | Script | Where | What it does |
|---|--------|-------|--------------|
| 1 | `01_download_data.py` | Kaggle/local (CPU) | Downloads benchmarks, freezes subsamples, writes `manifest.json` |
| 2 | `05_run_eval.sh` | Kaggle (GPU) | Accuracy evaluation via lm-evaluation-harness |
| 3 | `02_min_k_prob.py` | Kaggle (GPU) | Min-K% Prob contamination signal per item |
| 4 | `03_ts_guessing.py` | Kaggle (GPU) | TS-Guessing option-reconstruction test |
| 5 | `04_perturb.py` | Kaggle (GPU for MT) | Builds perturbed benchmark variants |
| 6 | `06_analyze.py` | local (CPU) | Aggregates outputs into Tables 3–5 + statistics |

## Setup (Kaggle notebook, first cell)
```bash
pip install -q transformers accelerate bitsandbytes datasets lm-eval sacrebleu sentencepiece scipy statsmodels
```
Add your Hugging Face token as a Kaggle secret named `HF_TOKEN`.
Accept licenses in the browser for gated models (Llama, Gemma) before running.

## Outputs
All scripts write per-item CSVs under `outputs/<model>/<benchmark>/`.
`06_analyze.py` reads everything under `outputs/` and emits `tables/table3.csv`,
`table4.csv`, `table5.csv` plus a `stats_report.txt`.

## Integrity rules (do not skip)
- Never edit `manifest.json` by hand after freezing.
- The probe set must remain offline (do not upload it to any public repo until after publication).
- Report numbers only from these outputs. No manual adjustment.

## Pilot data (completed 27 July 2026)

The `pilot_data/` folder contains the completed pilot run outputs (Qwen/Qwen2.5-1.5B-Instruct on 500 BoolQ-bn items, Colab T4, seed 20260727), generated by `pilot_boolq_bn.ipynb`:

- `pilot_results.csv` - summary: accuracy 0.568 (95% CI [0.524, 0.610]), perturbed accuracy 0.558, delta -1.0 pp, McNemar p = 0.302, Min-K%=20 mean -3.7673 (std 0.1865), 0.56 GPU-hours.
- `accuracy_items.csv` - per-item gold/prediction/correctness plus per-item Min-K% scores (500 rows).
- `mink_items.csv` - per-item Min-K% Prob scores at k=10 and k=20 (500 rows).

These per-item files allow independent re-verification of every summary number reported in the manuscript.
